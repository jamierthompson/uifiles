- inline-citation › description: "Inline citation badge for AI-generated text: a hostname pill such as \"ai-sdk.dev +2\" placed after a passage that opens a source card on hover, keyboard focus or a click/tap, containing a carousel of sources (title, URL, description, quote) with prev/next paging and an index. Use inside streamed responses to attribute claims to web or document sources."
- inline-citation › docs: "Built for the Base UI styles (base-nova): it composes the Base UI wrappers from components/ui and relies on their render prop and event signatures, so it does not work on Radix or React Aria styles. Base UI Preview Card puts hover delays on the trigger, not the root: InlineCitationCard no longer accepts openDelay/closeDelay; pass delay/closeDelay to InlineCitationCardTrigger instead (both default 0). InlineCitationCardTrigger composes HoverCardTrigger via render={<Badge render={<button type=\"button\" />} />} (no asChild): the badge is a real button, so it is in the Tab order and focus opens the card; remaining props (including onClick, which runs first and can preventDefault the toggle) still go to the Badge. InlineCitationCard keeps the open state itself (open/defaultOpen/onOpenChange still work and a press reports reason \"trigger-press\"): hover and keyboard focus peek at the card as in Base UI Preview Card, and a press on the badge (click, tap, Enter, Space) opens or pins it and moves focus to InlineCitationCardBody, where Tab and Shift+Tab cycle through the card's controls; a pinned card stays open when the pointer leaves and closes on Escape (focus returns to the badge without reopening it), on an outside press or on a second press. Upstream's Radix HoverCard has no press or touch path. A source that is not an absolute URL (relative path, bare host) is shown as given instead of throwing (try/catch, no URL.canParse, so Safari before 17 renders). InlineCitationCardBody is typed as the hover-card content props, so side/align/sideOffset/alignOffset type-check. InlineCitationCarouselPrev/Next are disabled at the first/last slide unless opts={{ loop: true }}, and have a 24px hit area and a focus ring; InlineCitationCarouselIndex follows slides added while streaming and reads 0/0 with none. A setApi passed to InlineCitationCarousel is called alongside the internal one. InlineCitationSource and InlineCitationQuote render nothing when they have no content (undefined, an empty or whitespace-only string, an empty array, or only null/boolean children). InlineCitationSource renders its title as <p> instead of <h4> so a hover card never breaks the page's heading order. InlineCitationCarouselIndex uses text-secondary-foreground on the bg-secondary header for AA contrast."
